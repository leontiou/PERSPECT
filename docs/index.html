PERSPECT Database

This database contains examples of 2D phantoms and GATE-simulated projection data, together with the corresponding GATE macro files and simulation details used with GATE v9.0. For some entries, the full projection matrix is not distributed because of its large size. In these cases, the corresponding GATE macro file is provided instead, allowing users to reproduce the simulation and generate the matrix locally.

The simulations were performed at the HPC Facility of The Cyprus Institute and were organized by Prof. E. Stiliaris .
