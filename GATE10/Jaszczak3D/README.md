# 3D Jaszczak voxelized phantom example

This subfolder contains an application of the GATE10 workflow to a **3D voxelized Jaszczak phantom**.

The purpose of this example is to demonstrate the projection-matrix generation workflow on a standardized synthetic phantom that is widely used in tomography. Compared with the anthropomorphic thyroid phantom example in the main folder, this case provides a simpler and more controlled test configuration.

The material in this subfolder may include:
- a notebook or script for constructing the voxelized 3D Jaszczak phantom,
- generation of the corresponding attenuation and source maps,
- GATE10 simulation outputs for selected projection angles,
- and reconstruction tests based on the generated projection matrix.

This example is intended as a complementary demonstration within the broader PERSPECT GATE10 workflow.
