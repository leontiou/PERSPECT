# Database of 2D phantoms and GATE-simulated projection matrices

This folder contains a collection of example **2D phantoms**, **sinograms**, and **GATE-simulated projection matrices** developed in the context of the **PERSPECT** project.

These datasets are provided as reproducible reference examples for the study and validation of tomographic forward and inverse modelling. In addition to the phantom and projection data themselves, the corresponding **GATE v9.0 scripts** and simulation details are also included, so that the examples can be inspected, reproduced, and extended by other users.

The database is intended to support transparent sharing of benchmark cases, allowing users to preview the phantom and sinogram visually before downloading the corresponding files and associated projection matrices.
